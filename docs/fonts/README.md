# Fonts

`RedHatDisplayVF.woff2` and `RedHatTextVF.woff2` are the Red Hat Display and Red Hat Text variable
fonts, the same files PatternFly (and therefore the Pulpit application) ships. Red Hat Fonts are
licensed under the SIL Open Font License 1.1: <https://openfontlicense.org/> — source and full
license text at <https://github.com/RedHatOfficial/RedHatFont>.
